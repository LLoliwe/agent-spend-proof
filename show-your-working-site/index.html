01 / THE OVERLOOKED MIDDLE

A correct answer tells you what. The working helps you ask why.

Assessment often focuses on where a learner ends up. We’re interested in the thinking along the way: the assumptions, revisions, uncertainties and moments where an idea changes. This project explores whether those traces can help educators respond more precisely.

AN ILLUSTRATIVE MOMENT

Sometimes the missing piece is another possibility.

A learner writes x = 5 after x² = 25. That solution is incomplete. Reveal the mathematical reasoning to explore a simple teaching opportunity. This example is hand-authored, not an automated grader.

WORKING NOTE / ORIGINAL EXAMPLE
x² = 25
x = 5…?
x = ±5

Both 5² and (−5)² equal 25. The negative root was missed. Ask why both possibilities matter.

Learning can start with one better question.
