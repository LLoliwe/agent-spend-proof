# Incident response runbook (P24, P48)

- **Decides on notification:** Lebohang Loliwe (Pryntor). For Tirisano data: Lebo and Mpho Loliwe.
- **Information Officer (POPIA):** Lebohang Loliwe (Pryntor (Pty) Ltd).

1. **Contain:** revoke or rotate exposed secrets first (P44); disable the affected feature or agent; preserve logs.
2. **Assess:** what data, whose, how many people, since when; is personal information involved?
3. **POPIA s22:** if personal information was or may have been accessed by an unauthorised person, notify the Information Regulator and affected data subjects as soon as reasonably possible after discovery, with the details s22 requires (possible consequences, measures taken, what people should do). Use the Regulator's current breach-reporting form.
4. **Fix and verify:** patch, retest, confirm with evidence.
5. **Postmortem:** blameless, timeline, contributing factors, actions as Linear issues with owners; within 5 working days.
