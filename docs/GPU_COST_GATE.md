# Pryntor GPU Cost Gate — R0 (17 Oct 2026)

Status: company-wide procurement **policy**, not a GPU Terminal deployment. Applies to paid GPU proposals only where a GPU is genuinely necessary.

1. Document model/job, data classification, required VRAM/GPU, variant, count, region, hours, SLA and why CPU/existing verified credits are inadequate.
2. Read the **public** https://gpu.context.dev dashboard. Record timestamp, exact filter settings, rate, observation age and original source link. Its prices are not guaranteed stock or checkout totals.
3. Independently verify at least two actually eligible vendors directly. Compare identical hardware and contract classes. Exclude unverifiable 'from' floors, committed multi-GPU bundles, and spot quotes for uninterrupted jobs.
4. Calculate total cost per **successful validated job**, including minimum spend, storage, egress, VAT, FX, failures, retries and migration overhead. Include existing credits and CPU baseline.
5. Log evidence in https://linear.app/pryntor/issue/PRY-223 and the actual workload issue. Require independent QA and finance/founder approval before new spend.

**Prohibited:** installing/self-hosting GPU Terminal, running paid monitors, connecting billing, renting GPUs, provisioning services, sending secrets or customer data to the dashboard, or declaring savings from list prices alone.

If no verified GPU need or direct quote: **NO NEW GPU SPEND**. Nothing here overrides project safety or CI gates.
