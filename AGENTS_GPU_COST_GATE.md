# GPU cost rule for repository agents

Before recommending any new paid GPU compute, read [docs/GPU_COST_GATE.md](docs/GPU_COST_GATE.md). Use GPU Terminal as a read-only comparison input; verify providers directly, document workload and total cost, and seek existing approval. Do not install, self-host, purchase, deploy, or claim savings automatically. This file is a proposed agent policy include, not a claim that every agent reads it. Link it from each repo's existing AGENTS.md only after review of current instructions.
